# Veonex

Veonex is an open-source game engine written in C#.

## Tech Stack

- **Graphics Render:** NeoVeldrid (Silk.NET)
- **Windowing & Input:** SDL3
- **Physics & Collisions:** BepuPhysics v2
  

## Status

Veonex is currently in early development.

The engine is ready for testing, but not for production yet
